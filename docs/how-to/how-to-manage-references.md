# Guide to Using the Shared Zotero Library and Managing References

We are centralising our academic reference library on zotero

## Accessing the Shared Zotero Workspace

This centralized approach is useful for ensuring that every piece of research references the same, accurate, and up-to-date source records. It will also make it easier to build our papers for both individual and group papers.

**Access Details:**
*   **Platform Location:** Install Zotero desktop https://www.zotero.org (its open source)
*   **Login Procedure:** You should have received an email after I added you to the group, if you havn't contact Stan

After logging into Zotero, the centralised group should appear as one of your libraries in the "Group Libraries" tab which is under the My Library section in the left toolbar.

## Maintaining the Core Reference Library (`references.bib`)

All bibliographic data for any published work must be sourced exclusively from the master `references.bib` file. 

### Utilizing Better BibTeX (Recommended Plugin)

It is highly recommend installing and utilizing the **Better BibTeX (BBT) Plugin** within Zotero. This tool significantly improves the workflow by providing robust management features, including advanced searching and ensuring the structural integrity of our exported bibliography data.

**Installation Steps:**
1.  Access the Zotero Plugin Manager.
2.  Search for and install the **Better BibTeX** plugin.
3.  Follow any specific setup guidelines provided by the plugin documentation.

> **Note:** To maintain data integrity, please avoid creating local copies of the bibliography library. All source additions and modifications must be performed directly within the shared Zotero environment.

### Workflow Guidelines for Contribution

References can be efficiently added to the library using the Zotero Connector https://www.zotero.org/download/connectors 
1.  **Input in Zotero:** Add the reference directly into the shared Zotero workspace using the browser tool when reading the source/journal
2.  **Export to BibTeX:** Once the reference is added, any annotations should be automatically shared and the reference should be exported automatically to the .bib file **(check this is working)**
3.  **Import into BBT:** The current manual step without some convoluted git trickery is to just manually drag the .bib file into overleaf for publication periodically. It feels like over engineering to go any further than that,
